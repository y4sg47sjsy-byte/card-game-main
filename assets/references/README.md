# Visual references

Place the user-supplied WANIN IP and visual-direction reference images in this directory. Keep the original filenames unless the user requests a rename, and list the chosen files in `config/card-manifest.yaml` after their roles are confirmed.

These files are image-generation inputs, not prompt-only descriptions. Before generating, Codex must open or display every selected image so the generator can see it. Do not infer WANIN identity or art direction from filenames alone.
