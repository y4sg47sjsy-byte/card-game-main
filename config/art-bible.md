# WANIN IP Art Bible

Status: `draft`

## Current scope

- The production IP is WANIN.
- No general WANIN world canon is defined in this file yet.
- Add only user-approved world, character, and visual-direction details here.
- For X-STARS character illustration work, use `config/x-stars-character-bible.md` as the authoritative input.

## Reference rules

- Each card's first listed reference is its primary identity reference.
- All other listed references contribute only their confirmed role, such as series-level rendering, lighting, detail density, or composition language.
- Reference files must be shown to image generation as actual visual inputs. A path in a prompt is not a substitute for loading the image.

## Prohibited drift

- No card frame, text, logo, watermark, or UI.
- Do not invent WANIN canon, character identity, card content, or art direction.
- Do not change a primary character's reference-defined identity colors, anatomy, costume, or accessories.
- Do not mix identity features between characters.
