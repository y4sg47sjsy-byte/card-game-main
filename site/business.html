X-STARS IP ECOSYSTEM

卡牌不是商品的終點，而是玩家進入 X-STARS 世界的起點

以實體收藏建立角色認知，再由遊戲、AI 互動、社群內容與線下活動深化關係，讓玩家從接觸品牌，逐步走向認同角色、收藏內容並參與 IP 發展。

FOUR TOUCHPOINTS

四個接觸點，共同經營角色關係

每個接觸點承擔不同任務，彼此導流，而不是各自獨立。

01

卡牌

負責收藏

用角色、卡面、系列與稀有度建立實體持有感，成為進入 IP 的具體入口。

02

遊戲

負責娛樂

以既有遊戲元素、活動與 Symbol 機制帶來首次接觸，並導向收藏與參與。

03

AI

負責互動與陪伴

依角色人格延伸聊天、攻略、娛樂、探索與收藏助手等不同使用情境。

04

社群

負責持續存在

透過角色日常、故事、生日、投票與玩家共創，維持非購買期間的接觸。

GROWTH FLYWHEEL

從一次消費，轉為持續角色關係

新系列與玩家參與會把動能重新帶回遊戲、收藏與社群。

  1. Acquire接觸遊戲、社群與活動認識 X-STARS
  2. Identify認同找到自己喜愛的角色與人格
  3. Collect收藏透過卡包、遊戲與活動取得卡牌
  4. Interact互動解鎖 AI、故事、造型與數位內容
  5. Participate參與加入投票、應援與下一季共創
  6. Return回流新系列讓玩家再次回到生態系
  7. Expand擴張導入既有遊戲 IP 與外部合作

AUDIENCE

三類核心受眾

既有星城玩家

用熟悉的遊戲元素降低卡牌門檻，提供新的收藏與參與方式。

角色收藏型玩家

以五位成員的人設、服裝、稀有度與限定系列建立收藏動機。

年輕社群與虛擬角色受眾

由角色、短影音、AI Chat 與共創內容成為認識品牌的第一接觸點。

VALUE FOR PLAYERS

對玩家

  • 遊戲娛樂與開包期待
  • 角色認同與收藏樂趣
  • AI 互動與限定故事
  • 社群參與及活動紀念

VALUE FOR THE BRAND

對星城品牌

  • 新的實體商品與年輕族群入口
  • 可長期經營的自有角色 IP
  • 既有遊戲資產再利用與雙向導流
  • AI 服務、社群內容與跨品牌合作載體

PHASED ROADMAP

以驗證為核心的四階段發展

不預設所有功能同步完成，以每階段的市場訊號決定下一步投入。

PHASE 1

卡牌 MVP

完成角色、第一彈卡牌、核心玩法與視覺規範，驗證玩家是否願意遊玩、辨識角色與收藏。

PHASE 2

角色品牌化

建立社群人格、故事、生日、Season 制與玩家投票，驗證角色偏好的形成。

PHASE 3

數位整合

加入遊戲聯動、數位收藏、實體卡解鎖與 AI 角色，建立線上線下雙向導流。

PHASE 4

IP 生態

發展遊戲聯名、外部合作、活動、商品與跨媒體內容，擴張角色資產的應用範圍。

ONE-LINE STRATEGY

以收藏卡牌為起點，透過遊戲建立娛樂、社群建立認同、AI 建立陪伴，打造 X-STARS 虛實整合的角色 IP 生態系。
